========================================
The TaskChain activity module for Moodle
========================================

TaskChain lets teachers combine several Hot Potatoes (versions 6 and 7),
TexToys, Xerte, iSpring and Qedoc exercises into a chain of tasks in a single
Moodle activity, with conditions that control which task comes next, and
with scores saved to the Moodle gradebook.

For full details, including installation instructions, see README.md
or https://github.com/gbateson/moodle-mod_taskchain

Downloads:
  - https://moodle.org/plugins/mod_taskchain
  - https://github.com/gbateson/moodle-mod_taskchain

To install:
  1. Unzip the zip file, and rename the folder to "taskchain".
  2. Put the "taskchain" folder in the "mod" folder of your Moodle site,
     (in Moodle 5.1 and later, this is "public/mod").
  3. Log in to Moodle as an administrator, and go to:
     Site administration > Notifications

For a single Hot Potatoes exercise, see the HotPot activity module:
  - https://moodle.org/plugins/mod_hotpot
